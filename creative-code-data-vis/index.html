Popularity of Musical Keys in Spotify Songs

Used this dataset: Kaggle Spotify Tracks Dataset

View code in Github

Looks like C and G major are the most common keys. Which is unsurprising. If I had more time, I would likely try to analyze and see if different keys are more common in other genres, and whether the keys are major or minor. I also wonder what this information "means" to people. I think most people don't discern between different keys, really. If they heard the same song played twice in two different keys, they difference wouldn't be meaningful. But to me, I feel like the key or tonality is something I listen for, and it makes a difference in the energy of a song.
