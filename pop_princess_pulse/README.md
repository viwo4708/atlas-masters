# POP PRINCESS PULSE
### [Demo Video](https://youtu.be/6zqJT2CZq-w)
### [Play the game in browser now!](https://vikkiwong.com/atlas-masters/pop_princess_pulse/)
This is a rhythm game that uses the mic to detect claps. You clap on the beats where the blue rectangles, or "notes"
fall into the target (you can also use the spacebar instead of clapping). For each one you miss or if you clap when there's no note in the target, you lose a life. But you also gain
lives back for each correct clap. So basically, you can't miss more than 7 claps in a row or you lose, which is harder than it sounds even for me, 
who charted the whole level by hand. 

**AI USAGE**
I used Gemini extensively to help me write the code for this, I am not representing this code as being handwritten by me. I needed a lot of help with 
the logic of how a rhythm game would work, and how to structure the functions and game states to make something like this work. I broke down each thing I needed
the game to do, ie having moving "notes" that go over a target on beat with the song, making an array of claps to feed into the game, doing the math for how the falling
"notes" are drawn, how to incorporate clap detection, etc. I did hand type most of the code into the IDE myself though to force myself to learn it and understand what
the AI was putting together. I did make the whole level by hand, it's important for me to have that human control over what the player experiences when they're actually
playing, and the graphics are not AI generated. Those are real pictures I took of myself, which is also important to me.
